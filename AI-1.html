01 · 개념

인공지능이란 무엇일까?

아래 문장의 빈칸을 클릭하면 답이 나타나요. 선생님 설명을 들으며 함께 채워봅시다.

DEFINITION
인공지능이란, 인간의 지적 능력을 구현하는 디지털 기술입니다. 사람이 학습하는 능력, 생각하는 능력, 말하는 능력 등을 컴퓨터 프로그램으로 실현한 기술이죠.
CORE IDEA
인공지능은 데이터를 기반으로 스스로 판단하고 학습하는 기술입니다.

이런 기술이 적용된 소프트웨어를 인공지능 소프트웨어/시스템이라고 불러요. 우리 주변에서 이미 만나고 있어요 👇

🎤음성 인식 서비스“시리야, 오늘 날씨 알려줘”
🎯추천 시스템유튜브가 알아서 골라주는 영상
🌐자동 번역기파파고, 구글 번역
02 · 특성

일반 소프트웨어와 뭐가 다를까?

버튼을 눌러 두 소프트웨어의 “규칙”이 어떻게 다른지 비교해보세요.

INPUT데이터
→
RULE정해진 규칙
→
OUTPUT결과

규칙이 고정되어 있어서, 똑같은 규칙대로만 결과를 냅니다.

즉, 인공지능 소프트웨어는 학습을 통해 스스로 규칙을 만들어내며 점점 성능이 좋아집니다.

03 · 학습 방식

머신러닝 vs 딥러닝

개와 고양이 사진을 구분하는 상황으로 두 방식을 비교해봅시다.

MACHINE LEARNING

🧑‍🏫 머신러닝

컴퓨터가 데이터를 보고 스스로 규칙을 찾아내는 기술. 단, 무엇이 중요한 특징인지 사람이 어느 정도 가르쳐줘야 해요.

💬 사람: “귀 모양이랑 꼬리 길이를 잘 봐!”
→ AI가 그 힌트로 구분 연습
DEEP LEARNING

🧠 딥러닝

인간의 뇌 구조를 본뜬 인공 신경망으로 학습하는 머신러닝의 한 종류. 사람이 힌트를 주지 않아도 스스로 특징을 찾아내요.

📸 사진 수천 장을 입력 → AI 혼자 개/고양이의 차이를 발견
